PostalScanner 2.1.2

- 다시 촬영 버튼을 [인식 결과 확인 완료] 바로 아래에 항상 표시
- 첫 촬영/일반 다음 문서 촬영은 기존 자동 촬영 유지
- 결과 확인 단계의 다시 촬영은 Space 단축키 지원
- 이름/주소/통수 입력칸 편집 중에는 Space가 공백으로 정상 입력됨
- 병합 셀 취소 시 ClearContents 대신 실제 저장 셀 Value 초기화 방식으로 변경
- 마지막 입력 취소 실패 시 개인정보 없는 처리 단계(연결/시트/셀/저장/검증)를 표시
- 기존 DPAPI, 저신뢰 확인, 시스템 점검, HTTPS+SHA-256 자동업데이트 유지
