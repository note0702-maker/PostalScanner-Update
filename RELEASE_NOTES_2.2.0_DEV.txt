PostalScanner 2.2.0 DEV

[OpenAI-only 정리]
- PaddleOCR / CLOVA 실행 코드 제거
- 일반우편/인감대장 판독 조건을 postal_rules.py로 분리해 보존
- 일반우편 K/T 영문 예외, 도/광역시 생략 주소, 상세주소/담당자 규칙 보존

[안정성]
- OpenAI 진단을 생성요청 대신 모델 접근 확인 방식으로 변경

- data 폴더로 업무데이터/설정 분리 및 2.1.x 데이터 자동 이전
- 원본 Excel이 없으면 배포 리소스에서 자동 복원

- 검증 완료 전 기존 설치 폴더를 변경하지 않음
- Updater를 설치 폴더 밖에서 실행
- 기존 설치를 통째로 백업한 뒤 검증된 새 폴더로 교체
- 새 PostalScanner.exe 존재/구조 검증 후 적용
- 새 앱 시작 실패 시 기존 버전 자동 롤백
- Updater는 onedir 빌드로 변경해 진행창 시작 지연 완화
